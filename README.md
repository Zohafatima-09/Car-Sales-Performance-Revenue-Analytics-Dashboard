# Car-Sales-Performance-Revenue-Analytics-Dashboard
An interactive car sales analytics dashboard built with Microsoft Power BI to analyze revenue, sales performance, commissions, and trends across car models, brands, and sales representatives.

This project is an interactive sales analytics dashboard developed using Microsoft Power BI. The dashboard provides insights into car sales performance, revenue generation, commission earnings, and salesperson productivity.

The goal of this project is to transform raw sales data into meaningful visual insights that help businesses monitor performance and make data-driven decisions.
